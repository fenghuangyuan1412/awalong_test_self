# 阿瓦隆（Avalon）安卓版 · 预览版 v0.1

> 一台手机/电脑即可完整游玩的《The Resistance: Avalon》数字版**本地热座预览**。
> 本仓库是完整项目（Unity 安卓版）的**先行可玩版本**：规则引擎已完成并经 2700 局模拟验证，
> 后续按《阿瓦隆安卓版-Agent开发提示词》的 Phase 路线图推进 Unity / 联机 / 上架。

---

## 🎮 立即游玩

**方式一（电脑）**：双击 `avalon-standalone.html`（单文件版，无需服务器），或启动本地服务后访问 `http://localhost:8000/`。

```bash
python -m http.server 8000
```

**方式二（手机，推荐）**：手机与电脑连同一 Wi-Fi，浏览器访问 `http://<电脑局域网IP>:8000/`
（IP 用 `ipconfig` 查看 IPv4 地址）。也可以把 `avalon-standalone.html` 直接发到手机，
用浏览器打开即可（部分机型支持"添加到主屏幕"当 App 用）。

## 🃏 支持内容

- **5–10 人**本地热座（传递设备），身份保密查看（传递确认 → 私密身份卡 → 视野提示）
- 全部核心角色：梅林 / 派西维尔 / 亚瑟的忠臣 / 莫甘娜 / 刺客 / 莫德雷德 / 奥伯伦 / 爪牙
- 完整流程：组队 → 全员投票（过半通过、平局否决、否决队长顺延）→ 秘密任务票 → 结算 → 刺杀梅林
- 官方规则细节：
  - 任务人数表按官方（如 5 人局 2/3/2/3/3，6 人局 2/3/4/3/4）
  - 7 人以上第 4 轮需 **2 张失败票**才算任务失败（界面有 ★ 标记）
  - 连续 **5 次**组队被否决 → 坏人直接获胜
- 对局日志、规则速查、终局身份揭晓、同玩家再来一局

## 📁 文件结构

```
avalon-preview/
├── index.html               # 主页面（UI 层，含样式与界面流程）
├── core.js                  # 规则引擎（纯 JS、零 DOM 依赖、数据驱动）
├── avalon-standalone.html   # 单文件分发版（build.py 自动生成，分享这个即可）
├── build.py                 # 构建单文件版：python build.py
└── test/
    └── simulate.js          # 规则测试 + 整局随机模拟（Node 或浏览器控制台运行）
```

## 🧪 测试

`test/simulate.js` 覆盖：

- 各人数角色配置表 / 任务人数表与官方规则一致
- 六种角色视野正确（梅林看不到莫德雷德、派西维尔看到双候选、奥伯伦孤狼等）
- 强制场景：连续否决 5 次判坏人胜；好人投失败票被引擎拒绝
- 随机整局模拟 5–10 人 ×300 局（含胜负路径、失败票数与结果一致性等不变量）
- 低通过率策略 150 局/人数，自然触发"5 连否决"路径

运行方式（任选）：

```bash
node test/simulate.js          # 有 Node 时
```

或：浏览器打开 `index.html` 后，在控制台粘贴 `test/simulate.js` 全部内容运行
（读取 `window.__simResults` 查看结果）。**开发时本文件即通过浏览器实机运行验证：✅ 全部通过。**

## 🏗️ 架构与后续路线

`core.js` 刻意与 UI 分离（状态机 + 纯函数动作 + 数据表），对应正式版的分层约束
（Core 层禁止依赖引擎 API）。未来 Unity 版直接按同构结构移植为 C#：

| 本预览版 | 正式版（Unity）对应 |
|---|---|
| `core.js` 状态机与数据表 | `Assets/Scripts/Core/`（纯 C#，NUnit 单测） |
| `index.html` 界面流程 | `UI/`（UGUI/UI Toolkit）+ `Game/` 粘合层 |
| 传递设备私密查看 | Phase 2 热座模式（可复用同一套交接交互设计） |
| — | Phase 4 联机（Netcode/Photon，房主权威校验） |
| — | Phase 3 美术音频、Phase 5 打磨、Phase 6 打包上架 |

完整路线见《阿瓦隆安卓版-Agent开发提示词.md》：Phase 0 设计基线 → 1 规则引擎 → 2 界面热座 →
3 美术音频 → 4 联机 → 5 打磨测试 → 6 打包上线（TapTap / Google Play）。
