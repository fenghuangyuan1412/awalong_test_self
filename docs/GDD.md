### 1.3 角色视野

- 梅林：看到所有坏人，**莫德雷德除外**
- 派西维尔：看到梅林与莫甘娜两位候选，无法分辨
- 坏人互相认识（刺客/莫甘娜/莫德雷德/爪牙），**奥伯伦除外**
- 奥伯伦：孤狼，双向不可见
- 忠臣：无视野

### 1.4 对局流程与胜负

1. 随机起始队长，身份保密展示
2. 队长提案组队（必须包含自己）
3. 全员公开投票：**同意票严格过半**通过（平局=否决）；否决后队长顺延下一位
4. **连续 5 次组队被否决 → 坏人直接获胜**
5. 队伍通过后，队员**秘密**出任务票：好人只能出成功；坏人可自选
6. 任务结算：1 张失败票即失败（★轮需 2 张）；任务票不公开是谁出的
7. 好人 3 胜 → 刺杀阶段：刺客指认梅林，指对坏人胜、指错好人胜；坏人 3 胜 → 坏人直接胜
8. 每轮任务结束后队长同样顺延一位

## 2. 数字化设计（当前实现）

- **流程状态机**：`propose → vote → mission → (循环) → assassinate / over`
- **热座隐私模型**：所有私密操作前插入"传递设备"确认页；身份卡需本人确认后才显示
- **公开信息**：任务结果与失败票数、历次提案与投票明细（对局日志可查）
- **私密信息**：角色身份、角色视野、任务票选择（永不公开是谁出的失败票）
